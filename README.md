# UN System Operating Model Analysis

This project is an evidence-based business analysis of the UN system. It looks at where value for money is lost, why entities stay fragmented, which changes would have the most impact, and who has the authority to make each one.

- `docs/`: project brief, methodology, findings
- `data/`: structured data (`raw/` holds the original downloads)
- `models/`: context diagrams, functional and cross-functional flows, flowcharts (Mermaid)

Everything here is built from public sources only.
